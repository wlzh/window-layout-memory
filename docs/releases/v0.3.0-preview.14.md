## 修复

- 仅已知微信标识 `com.tencent.xinWeChat` / `com.tencent.xinWeChat2` 下标题精确为“图片和视频”的标准窗口按子窗口处理，默认不自动铺满；开启“同时铺满子窗口”后允许。
- 微信聊天主窗口和其它应用不变。模态、未知父级及所有例外仍优先，横屏和竖屏共用规则。
- 不新增轮询、权限、依赖或持久字段，保留当前布局及偏好。已铺满窗口不会自动缩回旧尺寸。

## 验证与限制

规则依赖当前中文固定标题，不覆盖微信改名、其它语言和其它多开标识。采用原有签名方式及bundle标识，macOS仍可能要求重新授权辅助功能。未发布GitHub Release。
