2026-09-09，build 8，schema 1。本地开发预览，未发布GitHub Release。

## 修改

- 台前调度横屏铺满先请求尺寸，最多4次、间隔150 ms核验；宽高各误差不超过2 pt才写入位置，最后读回完整几何。失败不先左移，不新增空闲轮询。
- 普通布局与竖屏保存目标恢复保留原行为。跨屏铺满如果源屏限制目标尺寸会停止，不能保证所有应用接受AX缩放。
- 默认左侧100逻辑点。已有自定义值不会被暗中清除；新增菜单将当前组合所有横屏设为100 pt，不影响其它组合及布局基准。
