2026-09-12完成开发，2026-09-14发布GitHub prerelease；build 26，schema 1，MIT。公开资产为arm64 ZIP和SHA256，采用ad-hoc签名且未公证。

修复微信聊天记录按联系人逐一排除的问题。用户选择后按聊天记录类型排除，旧精确标题记录读取时合并为单一类型规则，不保留联系人姓名；其它例外和布局不变。仅识别标准窗口与已知微信应用标识，主窗口不匹配；不读取聊天内容，不新增轮询。未知标题仍需单独处理。
