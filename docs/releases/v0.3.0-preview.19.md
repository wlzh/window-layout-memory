# 0.3.0-preview.19

2026-09-12，build 26，schema 1，MIT。未发布GitHub Release。

修复微信聊天记录按联系人逐一排除的问题。用户选择后按聊天记录类型排除，旧精确标题记录读取时合并为单一类型规则，不保留联系人姓名；其它例外和布局不变。仅识别标准窗口与已知微信应用标识，主窗口不匹配；不读取聊天内容，不新增轮询。未知标题仍需单独处理。

新字段windowCategory仅接受wechatChatHistory，与标识、精确标题、扩展名互斥。旧版不支持此字段，不建议将新数据交给旧版读取。测试及安装结果见[测试报告](../TESTING.md)。
