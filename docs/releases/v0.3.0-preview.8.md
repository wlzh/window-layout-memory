移除原生最大化回退。build 11实机复现Telegram激活后变为1920 pt全宽，并报告尺寸失败；后续缩小未生效，留下四边铺满状态。现在仅请求尺寸、有限核验、成功后对齐；失败停止，不调用原生缩放或全屏动作。
