# 0.3.0-preview.20

2026-09-15，build 27，schema 1，MIT。未发布GitHub Release。

Telegram Lite在当前组合仅一条基准且仅一个观测窗口、双方无文档和窗口标识时，允许不依赖聊天标题匹配。其它应用不启用此兜底；多个窗口或多条旧记录不自动合并。此策略不是通用主窗口识别，AX未暴露其它窗口时仍有局限。

已有Telegram基准而身份未确定时不在当前屏幕自动铺满或新增铺满基准。自动铺满保存改变已匹配基准的显示器时必须有手动跨屏证据；手动保存仍是明确用户操作。无新增计时器、依赖或常驻扫描。

本机当前组合按用户确认的Mi Monitor备份后合并Telegram碎片记录；其它组合不猜测迁移。结果见[测试报告](../TESTING.md)。
