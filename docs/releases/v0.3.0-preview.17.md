# 0.3.0-preview.17

2026-09-12，build 24，schema 1，MIT。开发预览，未发布GitHub Release。

新增“永久排除此应用的 PDF 文件窗口”等类型入口，按窗口标题末尾受支持扩展名匹配，不区分扩展名大小写，不读取内容。按应用和窗口类型隔离，横竖屏共用；原精确标题、标识、临时规则保留，支持撤销及持久保存。

移除微信图片硬编码，已保存的用户图片规则继续生效且优先于子窗口开关。未配置规则的窗口回归通用策略。无新增轮询、权限或依赖；fileExtension与exactTitle互斥，旧规则可升级，不支持新字段的旧二进制不能直接读取新规则。

完整行为、支持范围和降级限制见[自定义规则](../CUSTOM_WINDOW_RULES.md)；测试及本机授权迁移见[测试报告](../TESTING.md)。
