# v0.3.0-preview.1

2026-09-08，build 5，MIT，arm64，ad-hoc签名，未公证；schema 1新增兼容偏好。

## 功能

菜单新增默认关闭的台前调度横屏自动铺满。系统台前调度开启且普通前台窗口稳定后，避开菜单栏和常驻Dock，预留左侧200 pt。左边缘中段拖动调整留白，按完整显示器组合和显示器ID持久记忆，同屏应用共享。

竖屏/正方形不处理。标题栏/其它边缘允许临时调整，下次激活再铺满。关闭开关本身不立即移动窗口。模式的横屏候选不进入普通布局基准，原布局保留。暂停、排除、未知系统状态和权限失效均不自动铺满。

## 边界

系统状态通过只读非公开约定的WindowManager偏好读取，未来系统升级可能改变，未知时不铺满。200 pt是可调初值，不是缩略图宽度自动检测。Dock隐藏时按屏幕边缘扩展，常驻时按系统可用区避让。应用最小/最大尺寸限制仍可能影响贴边，失败报告而不循环强制操作。

说明：[台前调度横屏铺满](../STAGE_FILL.md)。测试与实际验收状态：[测试报告](../TESTING.md)。自动化检查不代表实机与长期性能全部通过。

本地125核心、58协调器、12原生合成预览检查通过；核心行覆盖99.14%。release构建、签名、版本元数据通过。真实操作系统铺满与长期性能仍需独立验收，不宣称已全部通过。

安装前备份并退出旧版，不修改旧布局。新开关默认关闭，需从菜单开启；签名更新可能要求重新添加本应用辅助功能授权。导入备份会关闭自动铺满。降级旧版重新写入数据可能丢失新增留白偏好，建议保留备份。
