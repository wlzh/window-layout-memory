# v0.3.0-preview.5

2026-09-09，build 9，schema 1。[GitHub开发预览](https://github.com/wlzh/window-layout-memory/releases/tag/v0.3.0-preview.5)已发布，非稳定版。

新增“同时铺满子窗口”，默认关闭。多个独立主窗口仍可铺满，有明确父窗口的标准子窗口可选择启用。未知类型、对话框、Sheet和浮动面板不放行。应用将图片窗口暴露为普通独立窗口时不能自动识别，需要手动排除。

新增“铺满排除”：当前窗口临时排除，有AXIdentifier时可确认持久排除同应用、同标识、同角色的窗口，支持逐条撤销。无标识不做宽泛猜测。规则优先于子窗口开关；当前横屏处于铺满模式时不走自动恢复/学习旁路。关闭模式后普通功能照常。

默认左侧留白100 pt，移除独立菜单项。已有手动记忆值保留。延续先核验尺寸再移动策略。

旧schema 1数据缺省迁移到子窗口关闭、排除列表为空。布局和历史保持不变；旧版本不识别新偏好，降级后再次保存可能丢失新增偏好，降级前应备份。无新增包、网络服务、周期扫描、录屏或键盘监听。

253项本地功能检查、5项文档校验器测试通过。核心行覆盖率99.27%，Engine行覆盖率82.19%（注入AX）。安装包回下载SHA256、签名及与本机安装二进制比较均通过。当前辅助功能未授权，真实应用图片窗、物理多屏及长期性能验收未完成；GitHub CI状态见总览，不以本地结果替代。
