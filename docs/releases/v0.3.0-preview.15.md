# 0.3.0-preview.15

2026-09-11，build 22，schema 1，MIT。开发预览，非稳定版。

新增“竖屏保留左侧留白”，默认开启，旧配置缺失该字段时也开启。关闭后竖屏左右贴可用工作区，仍避让常驻Dock，保留纵向位置和高度，仅越界时修正。横屏不受影响。

开关全局持久保存，原显示器组合的留白值不清除；关闭时停止学习竖屏左边缘留白，重新开启使用原值。“同时铺满子窗口”为两个方向共用，包含既有微信看图规则；应用与窗口例外同样共用。

无新增轮询、依赖或权限。schema 1增加可缺省的布尔字段；导入仍关闭两个方向撑满，保留导入的留白偏好。安装、测试和未验收范围见[测试报告](../TESTING.md)，菜单见[使用指南](../USER_GUIDE.md)。未发布GitHub Release。
