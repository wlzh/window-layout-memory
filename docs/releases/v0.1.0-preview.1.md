# v0.1.0-preview.1

本页记录该版本发行与后续验证事实，不代表当前安装状态。最新源码、安装与已知问题见[状态总览](https://github.com/wlzh/window-layout-memory/blob/main/docs/STATUS.md)。

目标版本0.1.0，构建号1。**开发预览，非稳定发行。**

实现原生菜单栏、显示配置隔离、AX事件核对、前台候选、保存/锁定基准、保守匹配与一次恢复核验、历史/备份、排除/暂停、有限撤销与登录启动设置。

71核心用例/1,634断言通过，核心行覆盖98.41%（非全应用）。本地构建、安装启动、三屏只读识别、版本和ad-hoc签名验证通过。

**未完成全量需求验收，不应作为唯一布局工具。** 自动观察只产生会话内候选，需保存确认；后台窗口需激活。完整角色规则、显示器别名、启动其它应用、恢复重试等尚未完成。

台前调度开/关、实际多屏插拔、登录/唤醒、第三方窗口写入、10分钟代表性性能和8小时驻留均未完成验收。详见TESTING与COMPATIBILITY。

当前产物arm64，部署目标macOS13，本机检查macOS15.6。ad-hoc签名、未公证，不声明Intel/Universal兼容。归档与SHA256一同提供。

更新前退出应用并导出私人备份；安装脚本保留旧应用副本、不修改用户布局数据。签名变化可能需要重新授予辅助功能权限。
