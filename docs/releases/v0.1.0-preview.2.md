# v0.1.0-preview.2

本页记录该版本发行与后续验证事实，不代表当前安装状态。最新源码、安装与已知问题见[状态总览](https://github.com/wlzh/window-layout-memory/blob/main/docs/STATUS.md)。

开发预览，build 2，2026-09-07。MIT，arm64，ad-hoc签名，未公证；不是完整验收通过的稳定版本。

## 变化

- 自动记忆前台普通窗口的鼠标拖动和缩放，稳定后合并保存；新安装默认开启，旧版升级默认保持关闭。
- 仅标题栏/边缘鼠标证据允许自动学习；系统位置变化、焦点切换和恢复期间不能单凭几何变化覆盖基准。
- 布局重命名、显示器一对一手动映射复制、取消待恢复。
- 修复修订号变化导致重复自动恢复；重复布局不增加修订/历史或写盘。
- 减少AX监听器重复注册，支持过期扫描取消；未移动的临时写入失败最多重试一次。
- 103核心用例、2,814断言与28项假服务Engine集成检查通过。包括“相同内屏+不同外屏组合”各自独立窗口配置及落盘重载。具体覆盖率和限制见[测试报告](https://github.com/wlzh/window-layout-memory/blob/main/docs/TESTING.md)。
