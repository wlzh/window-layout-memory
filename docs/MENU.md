# 菜单导航

当前更新：0.3.0-preview.19 / build 26。微信聊天记录例外统一为类型规则：匹配以“的聊天记录”结尾的非空对象标题及“搜索聊天记录”，按应用标识和标准窗口类型隔离，横竖屏共用。旧聊天记录精确标题例外读取时合并；图片、PDF和其它规则不变。微信主窗口不在此规则内。安装与实测状态见 [测试报告](TESTING.md)。

适用：v0.3.0-preview.19 / build 26。新增竖屏独立的“竖屏保留左侧留白”，默认勾选，仅竖屏撑满开启且非忙碌时可编辑；关闭后不影响横屏留白。图片窗口不再有硬编码特例，已保存的用户例外优先于子窗口开关。聊天记录例外迁移不改变布局数据，不改变窗口匹配、显示器组合、100 pt初值或普通自动恢复策略。先移动再铺满规则见[铺满说明](STAGE_FILL.md)。

## 第一层

共12个入口（分隔线不计）：运行状态、布局预览、保存已核对窗口、恢复当前窗口、撤销最近恢复、四个功能分组、暂停/继续自动操作、关于、退出。退出保留Command-Q。

状态显示屏幕数及暂停/核对状态；缺少辅助功能权限时直接提供授权入口。详细状态放入提示与状态面板，版本统一从关于窗口查看。

## 完整结构

```text
运行状态 / 需要辅助功能权限…
布局预览…
保存已核对窗口（数量）
恢复当前窗口
撤销最近恢复
台前调度铺满 >
  横屏自动铺满
  竖屏横向撑满
    竖屏保留左侧留白（默认开启）
  同时铺满子窗口（横屏、竖屏共用）
  铺满例外 >（同一原生列表按分隔线分组）
    应用级：正在运行 / 已保存但未运行 / 从文件选择应用
    当前窗口：临时排除 / 按标识永久排除 / 永久排除标题：实际标题 / 永久排除此应用的 PDF 文件窗口（按当前扩展名显示） / 不可用原因
    已添加的窗口例外：临时和永久规则，点击取消
自动记忆与恢复 >
  自动核对窗口变化
  自动记忆手动调整
  自动恢复保存布局
  完全忽略应用 > 正在运行 / 已保存但未运行的应用
  关闭自动恢复并暂停
布局管理 >
  锁定/解锁当前布局
  重命名当前布局…
  关联已保存窗口 > 保存的角色
  从其它显示器组合映射 > 已保存组合
  恢复历史基准 > 历史记录
  导出布局备份…
  导入布局备份…
设置与诊断 >
  登录时启动
  权限与运行状态…
  重新核对窗口
暂停自动操作 / 继续自动操作
关于窗口布局记忆…
退出
```

最多两级子菜单。例外在同一原生列表内分组，不创建管理窗口，不增加层级。应用同名不同Bundle ID在名称中补充ID，完整ID可在提示中查看。未运行的已保存应用仍可取消例外。窗口目标取已核对的前台窗口；切换目标后重新打开菜单。不新增计时器、后台扫描或刷新任务。

## 行为边界

- 保存按钮仅保存已核对候选，不是截取整个桌面；没有候选或存储忙时禁用。
- 根菜单暂停是本次运行暂停，不改写自动恢复偏好；“关闭自动恢复并暂停”还持久关闭自动恢复。
- “应用例外”只限制台前调度铺满；“完全忽略应用”停止该应用全部布局核对，两者独立保存。
- 当前窗口临时例外不跨工具重启；按标识、精确标题或文件扩展名的用户例外均跨重启保存。无标识时仍可选标题；空标题不提供标题规则，详情见[自定义规则](CUSTOM_WINDOW_RULES.md)。
- 子窗口选项在两个方向铺满均关闭时不可操作；自动记忆在自动核对关闭时不可操作，但保留原有勾选值。
- 无基准、无其它组合、无历史记录时，对应管理操作禁用。历史基准恢复不直接搬动窗口。
- 菜单展开只读取已有引擎状态和一次运行应用列表，不做AX扫描、写盘、移动窗口或新增定时任务。

验证结果与实机限制见[测试报告](TESTING.md)，操作步骤见[使用指南](USER_GUIDE.md)。
