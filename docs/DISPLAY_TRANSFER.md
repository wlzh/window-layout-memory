# 当前窗口移屏

版本：0.3.0-preview.21 / build 28。

先激活需要移动的普通窗口，再打开菜单中的「移到其他显示器」，选择「← 左侧显示器」或「→ 右侧显示器」。菜单显示目标应用和显示器名称，操作只针对当前窗口，不移动应用的所有窗口。

- 依据显示器中心的水平坐标选取最近的左侧或右侧屏幕，不按显示器名称、ID或主屏排序。不循环；只有一屏、同水平中心上下排列、已到边缘时，对应方向不可用。
- 打开菜单时捕获窗口和显示组合；执行时重新检查前台应用、焦点、窗口几何和显示组合，变化则取消。不会把后来切换到的应用当成原目标。
- 普通窗口保留尺寸和相对位置；目标工作区更小时缩小并夹回，避开菜单栏和 Dock。
- 系统台前调度开启且目标屏幕对应铺满开关开启时，遵循横屏/竖屏、留白、子窗口和窗口/应用例外设置。铺满例外仍可手动移屏，但不自动铺满。
- 成功核验后立即保存到当前显示器组合，即使自动记忆开关关闭；这次点击代表明确的移屏意图，不应再被旧记录拉回。只更新当前窗口，不修改其它显示器组合。
- 布局锁定、暂停、权限不足、忙碌或完全忽略的应用不可操作。有已有记录但身份不能唯一匹配时拒绝移动，需先绑定窗口，不猜测覆盖。
- 原生全屏、最小化、无焦点窗口不支持。应用拒绝尺寸/位置修改时可能部分移动，显示错误且不覆盖保存值；写盘失败也会明确提示。

无额外轮询或常驻定时器。自动化测试使用合成窗口；真实菜单焦点、跨屏和不同应用的尺寸限制仍需实机验收。
