# 布局预览

在菜单栏选择“布局预览：当前 / 已保存 / 对比”。这是只读的几何示意图，不是屏幕截图。

## 查看方式

1. **当前布局**：显示当前组合最近成功读取的普通窗口。读取时间在详情中，不把后台窗口位置称为当前可见。
2. **已保存布局**：显示原始保存坐标，不冒充可用区域变化后的恢复目标。没有基准时显示空状态。
3. **对比**：蓝色实线是读取值，橙色虚线是基准；仅唯一匹配时计算位置/尺寸差值，歧义项单独保留。

按实际显示器排列和比例绘制，支持负坐标及竖屏。所有数值是全局左上角原点的逻辑点(pt)，不是像素。窗口跨屏时按最大相交面积标注归属；平分时显示待确认。

点击矩形或右侧列表选中窗口，重叠处重复点击可循环选择；列表支持方向键。底部显示应用、坐标、大小、屏幕及ID前缀、差值、读取时间。界面不显示窗口私人标题或文档路径，不读取截图。

## 不同组合

组合选择器可以查看其它保存组合。其它组合自动切换到保存视图，当前/对比禁用。相同Mac内屏在不同组合的记录仍独立，不与当前桌面叠加。

## 实时性与限制

打开时请求现有服务刷新一次，此后根据已有窗口事件更新。UI事件刷新最多10Hz，实际延迟受原有约0.6秒扫描合并、应用AX响应和焦点状态影响，不是视频帧率保证。不支持通知的应用需手动重新核对；不会为预览进行持续全窗口轮询。

台前调度后台组、隐藏或最小化窗口可能只能显示最近读取或已保存数据；示意图不代表真实可见性和遮挡顺序。显示配置过渡或授权失效时隐藏当前观察值，仍允许查看保存数据。

关闭后取消预览待执行刷新并释放面板、数据、闭包和绘图视图；后台布局记忆服务继续运行。首版不允许拖动示意图来移动真实窗口，也没有应用图标缓存。
