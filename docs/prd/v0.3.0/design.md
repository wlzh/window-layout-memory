# v0.3.0 交互

菜单增加勾选项“台前调度：横屏自动铺满（拖左边缘调整留白）”，开启前说明范围与原布局保护。状态面板显示功能开关、系统台前调度状态以及每屏保存的留白。

激活后等待窗口稳定，执行一次铺满；不循环抢鼠标。左边缘中段拖动后确认新留白，再对齐其它三边。标题栏/角落/其它边缘的调整保持到下一次激活。关闭开关不立即还原，用户可显式恢复原基准。

沿用现有原生菜单和状态面板，不新增常驻预览窗口。竖屏在详情中标明不处理；未知系统状态明确显示不铺满。
