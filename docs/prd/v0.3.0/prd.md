# v0.3.0 需求

2026-09-08。用户已确认横屏铺满、激活触发、自由调整和动态留白的需求，并要求实现、测试与版本说明一致。

1. 提供默认关闭的开关，仅系统台前调度开启且目标为横屏时铺满。
2. 缩略图点击、应用切换和窗口激活均可触发；仅处理前台普通窗口。
3. 避开菜单栏和常驻Dock，隐藏Dock时延伸到底边/对应侧边。
4. 默认留白200 pt，允许左边缘调整，按组合和显示器单独持久记忆，同屏应用共享。
5. 标题栏和其它边缘允许临时调整，下次激活再铺满。
6. 不覆盖普通布局基准；关闭后停止铺满，保留原布局可恢复。自动恢复开启且唯一匹配时，保存的显示器归属优先于铺满；目标竖屏按原布局恢复，不把系统挤压后的当前屏幕当作目标。
7. 无新增空闲轮询；无权限、未知系统状态、竖屏、镜像、排除或暂停时不铺满。

验收：目标几何与应用实际可设置几何各分量差值不超过4pt；原profiles/history不因铺满与留白调整变化；不同组合留白不串用。应用尺寸限制明确报告。实机ON/OFF、多屏、Dock模式及持续性能单独验收。
