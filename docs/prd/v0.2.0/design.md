# v0.2.0 预览交互

顶部为三段视图切换与组合选择，下方状态说明最近读取与后台可见性的区别。主体左侧按实际屏幕关系绘制布局，右侧为可键盘选择的窗口列表，底部显示选中项的精确数据。

蓝色实线表示最近读取，橙色虚线表示保存坐标；同时保留文字标签，不仅依赖颜色。重叠窗口可通过列表选择，也可重复点击重叠区域循环选择。保存与当前位置靠近时只绘制一次应用名称，避免文字重影。

选择其它组合时自动进入保存视图，禁用当前/对比；返回当前组合后重新启用。窗口未匹配、匹配歧义、无权限、无基准分别显示明确说明，不造出对应关系。

使用原生AppKit外观、原生控件、窗口列表和可选择文本。最小窗口860×540，默认1120×720。应用名称不包含私人窗口标题；首版不加载应用图标缓存。
