# v0.2.0 布局预览需求

用户已确认只读预览方案并要求实现。目标是直观核对完整显示器组合的窗口几何，而非采集屏幕内容。

- 菜单栏提供布局预览入口，面板支持调整大小。
- 显示器保持真实排列、宽高比例、负坐标及横竖方向。
- 当前、已保存、对比三种视图；当前表示最近成功读取，不保证后台可见性。
- 完整显示器组合隔离；其它组合仅显示其保存数据，包含独立的内屏记录。
- 选择窗口显示应用、位置、大小、显示器归属、读取时间及有唯一匹配时的差值。
- 不展示私人标题、文档路径或窗口内容，不要求录屏权限。
- 事件驱动更新，无预览专用周期扫描；关闭释放面板、数据和待执行任务。
- 台前调度开启、关闭均需实机验收；模拟测试不能替代实机通过。

不支持在示意图内移动真实窗口，不承诺显示真实遮挡顺序。旧版完整多屏、登录和性能门禁仍保留，不因新增预览而宣称全部完成。
