# v0.1.0 交互设计

状态：目标交互规范已确认，开发预览已部分实现；完整设置与规则界面尚未完成。需求见 [PRD](prd.md)，实际限制见 [兼容性](../../COMPATIBILITY.md)。

## 1. 展示原则

轻量菜单栏应用，无常驻主窗口；不提供分屏动画、窗口缩略截图或实时预览流。
界面优先中文，使用系统原生控件、键盘导航、文本状态与系统外观。
不打断工作、不自动展开隐藏窗口；错误优先在菜单栏面板聚合显示。

## 2. 菜单栏

```text
Window Layout Memory
当前配置：三屏 / 布局：日常工作
状态：已就绪 · 已记忆 12 · 待激活 3 · 需确认 1
---------------------------------------------
保存当前布局…
恢复当前布局…
撤销最近恢复
暂停自动操作
---------------------------------------------
布局与窗口…
设置…
权限与诊断…
关于…
退出
```

恢复按钮在权限缺失、显示配置变化中或无基准时禁用，并说明原因。
“已记忆”不等于“本次已恢复”；等待中的窗口不进入成功计数。
暂停显示清晰状态，禁用自动学习与自动恢复；手动操作仍需显式确认。

## 3. 首次设置

1. 说明本地存储与辅助功能权限用途，展示前往系统设置按钮。
2. 展示实际检测到的屏幕与排列，不修改显示器配置。
3. 枚举可确认的普通窗口，隐藏/不可访问窗口显示待激活。
4. 台前调度用户可依次激活各组，再回到应用确认采集结果；未开启时同样可直接采集。
5. 用户命名并保存第一份基准；自动记忆默认选中，自动恢复与登录启动分别明确授权。

没有可信尺寸的窗口不得显示为“已保存完成”。不要求关闭台前调度，不自动改系统偏好。

## 4. 布局与窗口

左侧：配置列表（显示器名称和布局名）；右侧：窗口列表与详情。
屏幕仅用静态比例示意，不截屏；关闭窗口后释放展示缓存。

窗口列表列：应用、角色、屏幕、尺寸、位置、状态、最近更新时间。
普通桌面与台前调度使用同一列表和术语，不需要用户手动选择工作模式。

状态：已确认、候选调整、待激活、待出现、身份歧义、不支持、恢复失败、已排除。
失败项展示原因为何、下一步操作及最后成功时间，不只显示图标。

## 5. 保护与纠错

- 锁定基准：锁定后新变化可作为候选，但不能替换基准。
- 历史：按时间查看快照，恢复配置基准与实际移动窗口是分开的操作。
- 歧义：选择窗口角色与匹配条件，并展示规则命中情况；不允许两个角色绑定同一个窗口。
- 恢复预览：列出将移动、等待、跳过的窗口；手动操作提供取消。
- 撤销：展示将恢复的数量；显示配置已变化时禁用旧撤销并解释。
- 应用排除：立即取消该应用待处理动作，保存记录不自动删除。

删除配置与清空历史需要确认，不因关闭应用而自动删除。

## 6. 设置与诊断

设置项：自动记忆、自动恢复、登录启动、默认恢复策略、应用排除、历史保留上限。
“自动打开应用”为独立可选项，不默认打开；明确不承诺重新打开文稿或标签。

诊断显示监听能力、权限、当前配置、失败计数和资源统计入口。统计不在普通运行中持续采样。
导出默认脱敏，导出原始布局提示标题与文稿路径可能包含私人信息。
版本与关于页面展示版本号、构建号、MIT、项目地址及签名/公证状态。

## 7. 两种模式的体验一致性

关闭台前调度时，小尺寸普通窗口不是错误，不因尺寸小自动排除。
开启台前调度时，侧边预览不展示为可恢复目标。
模式切换中显示“等待窗口稳定”，不强行保持旧焦点、不反复搬回窗口。
若系统接口不能可靠区分某窗口状态，显示“需激活核对”，而不是作无依据的成功承诺。
