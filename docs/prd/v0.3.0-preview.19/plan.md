# 聊天记录类型例外：plan

0.3.0-preview.19 / build 26，2026-09-12。

目标：一次选择覆盖不同联系人的聊天记录与搜索聊天记录，不误排除微信主窗口。按bundle、role、subrole限制；无用户规则不自动排除。支持横竖屏共用和菜单撤销。

实现：windowCategory=wechatChatHistory，互斥验证；旧精确标题规则在解码时规范化并按原顺序去重，非法输入仍拒绝。图片与PDF规则保持原样。联系人名称不写入新类别规则。

验证：不同联系人、搜索、主窗口、跨应用、对话框、非法混合字段、旧数据合并和往返、菜单持久化与撤销。自动测试不替代真实微信、多屏及长期耗电验收。结果见[测试报告](../../TESTING.md)。
