# 子窗口铺满策略需求

## 范围

用户希望图片等辅助窗口保留自然尺寸，主窗口继续铺满。新增默认关闭的子窗口选项；普通多个主窗口不能因为打开顺序被误判。无可靠识别信息时允许手动排除当前窗口，不承诺所有应用图片窗自动识别。

## 验收

- 子窗口默认不铺满，明确开启后标准子窗口可铺满；对话框及浮动面板始终保护。
- 临时排除、可持久识别的排除规则都可撤销，且优先于子窗口开关。
- 被排除的横屏窗口在铺满模式中不能被自动恢复旁路移动或自动学习。
- 总开关和系统模式关闭后，原有普通布局功能保持；所有组合基准及历史不被策略修改。
- 默认留白100 pt，不新增单独菜单，保留已有手动留白。
- 文档、版本、回归测试保持一致；真实应用验收与自动测试分开报告。
