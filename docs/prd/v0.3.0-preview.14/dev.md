# 微信看图窗口：实现

`StageWindowTraits.permits` 新增可选 `WindowIdentity` 参数，在原有角色、模态、父级门禁之后附加限制：两个已知微信 bundle 中标题精确为“图片和视频”的窗口必须启用子窗口选项。不是通用标题推断，不扩展 bundle 前缀匹配。

`Engine.stagePermits` 传入已有身份，所有使用此共用入口的铺满和恢复/学习过滤路径共享规则。无需新扫描、计时器、依赖、权限或持久字段，schema 1保持不变。

核心测试覆盖开关、两个 bundle、非微信同名、近似标题、聊天窗口与安全门禁；引擎测试覆盖入口传参。版本元数据为0.3.0-preview.14 / build 21。
