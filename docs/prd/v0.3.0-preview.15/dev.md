# 竖屏留白：实现

Preferences增加 `stagePortraitKeepInset`，初始化和缺字段解码默认true。schema仍为1；合成编码保存该布尔值，导入保持原有两个撑满开关关闭策略。

`stageInset(topology:display:)`统一计算有效留白：竖屏且关闭选项时返回0，否则按原组合/屏幕记录或默认100。Engine目标与诊断复用该函数。竖屏不留白时跳过留白手势学习与写入，继续普通竖屏横向撑满事务及成功保存。

不增加轮询、监听、依赖或权限；既有后台队列、取消、锁定、例外和失败保护不变。版本0.3.0-preview.15 / build 22。
