# 自定义窗口例外：实现

StageWindowRule增加可选exactTitle字段；nil保持旧标识匹配。标题规则要求identifier为空，匹配bundle、role、subrole和完整标题，不做模糊或大小写折叠。空白、超长、混合规则拒绝，与旧规则共用200条上限。

引擎共用stagePermits，覆盖铺满和对应恢复/学习旁路。菜单动作重新核对当前目标及规则，避免陈旧选择。原子持久化、取消在途任务、错误保护沿用setPreferences。

schema仍为1，旧标识数据升级可读；旧二进制无法解释标题规则并拒绝此数据，降级需撤销标题规则或还原备份。无新增依赖、权限或轮询。
