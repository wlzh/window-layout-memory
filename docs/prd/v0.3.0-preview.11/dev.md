# 技术设计

Engine用stageUserDisplays保存当前配置下具有明确鼠标证据的运行时换屏意图，stageDestination优先使用该意图；拓扑、权限、设置或模式改变时失效。普通恢复仍使用当前组合的已保存归属，不从系统几何变化推断用户意图。

AX完成回调核验最终目标，再用有界stageSaveQueue暂存待写结果。drainStageSaves重新检查配置、权限、前台、鼠标、目标、缓存几何、锁定和唯一匹配，经CaptureMerge更新同一窗口ID，Database.replace保留历史。已有IO完成后再排队合并，不新增空闲定时器；失败队列清空并报告。

已铺满且稳定的窗口也可保存当前几何；相同记录不写入。无身份线索的新窗口不自动生成不可匹配记录。明确移入竖屏仍走普通鼠标自动保存条件，不称为横屏铺满。

新增外部接口、依赖、持久字段及迁移：无；schema仍为1。内部变更为Engine路由、完成保存和UI说明。布局备份继续使用原格式。
