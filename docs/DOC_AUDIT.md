## 验证与边界

运行`ruby scripts/check-docs.rb`检查所有本地Markdown文件链接目标、PRD四件套、版本文件/plist/AppVersion一致，以及主要作者和网站引用。检查不启动应用、不签名、不访问网络；不验证URL远程可达性、Markdown锚点或所有自然语言语义。脚本结果和`git diff --check`应为无错误；这些不计入应用的215项功能检查。

本轮实时核对：GitHub最新预发行和本机安装均为0.3.0-preview.2 / build 6；main修复提交c5a2836的CI成功。未发行修复不在已上传build 6归档内。本轮不重新运行硬件或长期性能测试，不推进版本、不安装、不变更签名，也不把微信未解决问题标为完成。

本地检查覆盖31份Markdown、84个本地链接，0错误；版本为0.3.0-preview.2 / build 6。`ruby scripts/test-docs-check.rb`用临时副本验证正常文档、断链、build不一致、AppVersion回退值不一致、作者网站缺失，共5项，避免校验器只会报告成功。检查规模会随文档增加而变化，以脚本即时输出为准。
