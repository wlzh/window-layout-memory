# 兼容性与已知缺口

状态日期：2026-09-08。代码存在、测试通过和稳定支持是不同结论。

v0.2.0新增预览已完成114核心、32协调器及12项原生合成检查。真实AX数据对照、最新台前调度完整切换和性能仍需实机验收；预览不表示后台窗口当前可见或真实遮挡层级，详见[预览说明](PREVIEW.md)。

| 范围 | 结果 |
| --- | --- |
| macOS15.6 / arm64 | 构建、安装、启动和三屏只读识别通过 |
| macOS13/14及其它版本、Intel | 未实机验证；本次只提供arm64产物 |
| 台前调度开/关/运行中切换 | 都是P0目标，完整实机窗口恢复未验收 |
| 外部窗口AX读写 | 已授权旧版实际读取9个窗口；新版写入E2E待测试 |
| 后台/隐藏/最小化窗口 | 等待激活，不强制切组或展开 |
| 同质多窗口 | 保守歧义处理，不保证重启后完全区分 |
| 镜像配置 | 安全拒绝 |

## 未完成项

1. 自动学习仅覆盖具有鼠标标题栏/边缘证据的调整，其余变化需手动保存；并非所有输入方式均可无感学习。
2. 已实现手动显示器映射复制和重命名；不维护自动别名表，不猜测未知显示器。
3. 未实现完整窗口角色规则编辑器。
4. 未实现启动第三方应用或重建文稿/标签。
5. 临时AX错误且无任何几何变化时最多重试一次；部分写入或应用尺寸约束不重试。
6. 各应用AX通知支持与实际台前调度几何尚未逐项验证。
7. Engine已增加假服务集成回归；真实AX适配器、GUI没有完整自动化覆盖报告。
8. 实际插拔、登录/唤醒、代表性双模式性能和8小时驻留尚未验收。

## 范围外

Spaces、原生全屏、台前调度分组顺序、完整遮挡层级、任意应用内部会话与未保存内容恢复。

仅通过核心测试不得声称“完全满足需求”。详见 [测试报告](TESTING.md)。
